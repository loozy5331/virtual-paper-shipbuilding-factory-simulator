## 1.1: 발표 버전 (2026-10-08 동결, `v1.1.0`)

남은 시간이 종일 3번과 저녁 7번 정도라, 반쯤 하다 멈춰도 1.0보다 나빠지지 않는 일만 넣는다(D1).

- 설정창 가독성
  - 자재 발주일 입력 대신 발주 방식 `bulk`(일괄) / `jit`(역산) / `late`(늦은 발주) 중 하나를 고른다. "전체 발주일 역산" 버튼은 없앤다(D3)
  - 프리셋: 무관리 `late`, 관리 `jit`, 전부 최대 투입 `bulk`(D4)
  - 착수일은 숫자 대신 계획 간트에서 막대를 끌어 정한다. 같은 작업장을 두 배가 겹쳐 쓰는지 보인다(D5)
- UI 인상: 클립보드 위에 얹은 종이(D2)
  - 계획 = 생산계획서, 관제실 = 공정 실적표, 레포트 = 생산실적 평가서 (D2 수정, 아래 handoff 참고)

## 1.2: 관제실 기호도 (2026-10-08 완료, `v1.2.0`)

- 관제실 = 현장을 추상화한 2D 기호도 + 간트, 현장 = 생동감 있는 3D. 관제실은 "어디서, 언제", 현장은 "왜"를 보여 준다. 같은 `frame.ts`를 다르게 그린다(D6)
- 현장 보기는 의문점 카드, 기호도 작업장, 간트 막대 세 곳에서 들어간다. 전환은 포스트잇 + 클립보드 내려가기(D7)

## 2.0: 4M 선택지와 트레이드오프 (D10, D11)

수업에서 학생이 쓰는 도구로 만든다. 1.x의 선택지는 대부분 켜면 좋아지는 스위치라 정답이 뻔했다.
2.0에서는 모든 선택에 Q·C·D 중 하나 이상의 대가를 붙여, 전략으로 최적에 도달하게 한다.

- 4M 선택지(설정 v2, MAJOR). 공정별로 고른다
  - 사람: 일반 / 숙련공(불량↓, 단가↑, 부상 위험) / 로봇(유지비↓, 초기비↑, 고정 불량률) / 야간작업(진행↑, 불량·사고↑)
  - 설비: 등급별 성능·고장률·가격, 공정별 작업장 증설(1~2대, 서로 다른 배를 동시에 처리, D16)
  - 공법: 표준 / 속성 / 최신 자동화 공법(비용 효율, 초기 불량↑)
  - 자재: A4(보통) / 휴지(단가↓, 불량 크게↑)
- 균형 점검 `engine/tools/balance.py`: 조합을 모두 돌려 지배 전략이 없는지 확인한다(D15)
- 저장: 수업용 닉네임 + 반 코드, 반별 최고 등급. 사용자 표와 인증 표를 처음부터 나눠 나중에 로그인을 붙인다(D8). sqlite3
- 기술 스택은 그대로 둔다(D14)
- 시나리오 둘: 기본 분기(4척)와 수주 증가(6척, LNG선 2척). 공통 규칙 1개 + 시나리오 파일(D17, D20)
- 3D: 증설한 정반·크레인 자리. 선종은 이름표로만 구분

## 2.1: 선종별 배 모양과 소인국 (D21)

- 배 모양을 선종에 맞게: 컨테이너선은 적재 구조, 선미의 높은 선실, 러더 같은 의장품이 탑재 때 붙는다. 종이로 접은 질감은 남긴다
- 소인국 배경, 뒤에 누운 걸리버가 골리앗 크레인 역할, 걸리버 손 디자인
- 그림만 바뀌고 설정·결과 모양은 그대로라 MINOR
