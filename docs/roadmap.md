## 1.1: 발표 버전 (2026-10-08 동결, `v1.1.0`)

남은 시간이 종일 3번과 저녁 7번 정도라, 반쯤 하다 멈춰도 1.0보다 나빠지지 않는 일만 넣는다(D1).

- 설정창 가독성
  - 자재 발주일 입력 대신 발주 방식 `bulk`(일괄) / `jit`(역산) / `late`(늦은 발주) 중 하나를 고른다. "전체 발주일 역산" 버튼은 없앤다(D3)
  - 프리셋: 무관리 `late`, 관리 `jit`, 전부 최대 투입 `bulk`(D4)
  - 착수일은 숫자 대신 계획 간트에서 막대를 끌어 정한다. 같은 작업장을 두 배가 겹쳐 쓰는지 보인다(D5)
- UI 인상: 클립보드 위에 얹은 종이(D2)
  - 계획 = 생산계획서, 관제실 = 공정 실적표, 레포트 = 생산실적 평가서 (D2 수정, 아래 handoff 참고)

## 1.2: 관제실 기호도 (2026-10-08 완료, `v1.2.0`)

- 관제실 = 현장을 추상화한 2D 기호도 + 간트, 현장 = 생동감 있는 3D. 관제실은 "어디서, 언제", 현장은 "왜"를 보여 준다. 같은 `frame.ts`를 다르게 그린다(D6)
- 현장 보기는 의문점 카드, 기호도 작업장, 간트 막대 세 곳에서 들어간다. 전환은 포스트잇 + 클립보드 내려가기(D7)

## 2.0: 4M 선택지와 트레이드오프 (D10, D11) — 2026-10-09 완료, `v2.0.0`

수업에서 학생이 쓰는 도구로 만든다. 1.x의 선택지는 대부분 켜면 좋아지는 스위치라 정답이 뻔했다.
2.0에서는 모든 선택에 Q·C·D 중 하나 이상의 대가를 붙여, 전략으로 최적에 도달하게 한다.

- 4M 선택지(설정 v2, MAJOR). 공정별로 고른다
  - 사람: 일반 / 숙련공(불량↓, 단가↑, 부상 위험) / 로봇(유지비↓, 초기비↑, 고정 불량률) / 야간작업(진행↑, 불량·사고↑)
  - 설비: 등급별 성능·고장률·가격, 공정별 작업장 증설(1~2대, 서로 다른 배를 동시에 처리, D16)
  - 공법: 표준 / 속성 / 최신 자동화 공법(비용 효율, 초기 불량↑)
  - 자재: A4(보통) / 휴지(단가↓, 불량 크게↑)
- 균형 점검 `engine/tools/balance.py`: 조합을 모두 돌려 지배 전략이 없는지 확인한다(D15)
- 저장: 수업용 닉네임 + 반 코드, 반별 최고 등급. 사용자 표와 인증 표를 처음부터 나눠 나중에 로그인을 붙인다(D8). sqlite3
- 기술 스택은 그대로 둔다(D14)
- 시나리오 둘: 기본 분기(4척)와 수주 증가(6척, LNG선 2척). 공통 규칙 1개 + 시나리오 파일(D17, D20)
- 3D: 증설한 정반·크레인 자리. 선종은 이름표로만 구분
- 만들며 더한 것(D22, D23): 첫 화면(분기별 클립보드), 생산계획서(A안·B안·C안 탭, 포스트잇, 펜 서명), 관제실 1인칭(모니터 두 대, CCTV, 평가서 클립보드), 작업모로 현장 나가기
- 계획에서 바뀐 것: 야간작업은 잔업 그대로, 설비 등급은 정비와 겹쳐 뺐다, 시니어는 숙련공에 흡수(D22)

## 3.0: 구역과 작업장, 블록 단위 병렬, 안전 (D26, D27) — 2026-10-09 완료, `v3.0.0`

설정 모양이 바뀌어 MAJOR다. 코드보다 규칙 문서를 먼저 고친다(2.0과 같은 방식).

- 공정을 구역(area)으로, 구역 안에 작업장 1~3개(상한 3). 4M은 2.0처럼 공정마다, 모든 작업장에 같게(D30, 작업장별 예외 없음). 규칙 문서 본문 3·4·10장
- 설정 `areas.<공정>` = 작업장 수 + 4M + 나눠 하기(`split`). 1.x·2.x 설정(`stations.<공정>.units` 1~2)은 그대로 읽는다(하위 호환)
- 화면 용어: "소조립 구역 · 1호 작업장". 그림 속 바닥은 조립 구역 "정반", 탑재 구역 "도크"
- 새 분기 "수주 급증"(8척, D31): 3호와 나눠 하기의 판단 거리. 엔진은 브랜치 `feat/v3-engine`(테스트 57개)
- 블록 단위 병렬(D13)과 함께: 로트를 어느 작업장에, 나눠서 넣을지가 같은 배정 루프의 질문이라 엔진을 한 번에 고친다
- 안전: 위험 설비(골리앗 크레인, 운행 중인 트랜스포터) 반경 출입 금지. 현장 바닥에 통제선과 "반경 10m 출입 금지" 팻말, 작업 현황 전경에 점선 원, 소인은 작업 중인 반경을 지나가지 않는다. 현장에 나가면 시간이 멈춰 있고 재생은 1배속 고정(2.1.4에 먼저 넣음, 하루 2초), 관리자는 "작업장 앞 / 보행 통로"에 선다. 움직이는 설비의 반경이 관리자 자리에 닿으면 자동으로 멈추고 경고, 평가서에 경고 횟수(등급 점수에는 넣지 않는다, D28). 크레인 작업일에 반경 안 작업장을 멈추는 엔진 규칙은 작업장 배치가 정해진 뒤 검토
- 화면: 계획서의 공정 카드 → 구역 카드 + 작업장 줄, 작업 현황 전경과 현장 3D는 구역 안에 작업장 N개
- 미룬 것: 재생 중 자동 안전 경고(→ 4.10), 크레인 반경 안 작업장을 멈추는 엔진 규칙(→ 하지 않음, 4.0 참고)
